## 본인 기여 구분

- Instagram DM 발송은 **기존 프로그램을 분석하고 최적화한 작업**입니다. 최초 프로그램 전체를 단독 개발한 것은 아닙니다.
- ASF, HC, MySQL 관리 스크립트, Threads 자동화, Vling 관련 업무에서 설명한 작업은 본인이 직접 수행했습니다.
- 학교 실습일지는 3개월간 수행한 업무를 15개로 정리한 자료이며, 실제 15일 출근 기록이 아닙니다.
- 2024년 10월 Vling 작업은 인턴 기간과 별도입니다.
- 과거 지원자료에 나오는 검증되지 않은 시간 단축 및 데이터 품질 개선 수치는 사실로 재인용하지 않았습니다.

## 공개 자료의 범위

이 저장소 및 링크된 기능별 저장소는 **회사 원본 코드, 데이터베이스, 수집 결과, 고객 정보, API 키, 내부 운영 문서를 포함하지 않습니다.** 기능별 `demo.py`는 포트폴리오 설명을 위해 새로 작성한 **오프라인 교육용 예제**로, 2024년 실제 소스나 원본의 배포 버전이 아닙니다.

직무별로 실무 경험을 이해할 수 있도록 배경, 설계 판단, 직접 수행한 활동과 보안상 공개하지 않는 범위를 구분해 기술했습니다. 프로젝트의 코드 공개와 저작권 사용 허가를 혼동하지 않기 위해 원본 파일은 어떤 저장소에도 업로드하지 않았습니다.

## 포트폴리오 읽는 방법

제조 IT 및 시스템 운영은 DB 관리와 프로세스 자동화, 데이터 직무는 ASF/HC와 Vling 파이프라인, 개발 직무는 기존 DM 최적화 및 오류 대응 기록을 중심으로 참고할 수 있습니다.

연락처와 개인 학교 서류, 회사 직인 문서는 공개하지 않습니다.
