# DinoStudio 실무 인턴 및 별도 프로젝트 포트폴리오

2024년 실무 인턴과 별도 프로젝트에서 직접 진행한 Python 자동화 및 데이터 처리 경험을 기능별로 정리한 공개 포트폴리오입니다.

**실무 인턴:** 2024년 7월 1일 ~ 9월 30일 (3개월)  
**별도 프로젝트:** 2024년 10월 약 2주, Vling 정보 수집 및 저장

**공개용 데모:** 실무 경험을 바탕으로 2026년에 별도로 구현한 데모입니다. 회사 내부 자료와 원본 코드를 보호하기 위해 가상 데이터를 사용했으며, 2024년 실무 구현과 공개 데모의 검증 범위는 구분합니다.

## 실무 경험의 흐름

기존 Instagram DM 업무 프로그램을 분석하면서 사용하지 않는 기능을 정리하고 데이터 관리와 오류 대응 방식을 개선했습니다. 이후 판매자 후보 탐색과 활동 이력 수집, DB 관리에 필요한 프로그램을 직접 작성했습니다. 별도 Vling 프로젝트에서는 채널과 영상 데이터를 수집하고 저장하며, 조회와 수동 정보 관리 기능을 구현했습니다. 각 저장소의 실무 설명은 당시 작업을 기준으로 하고, 공개 코드에서는 실제 운영 자료 대신 가상 입력으로 동작을 재현합니다.

## 본인 기여 구분

- Instagram DM 발송은 **기존 프로그램을 분석하고 최적화한 작업**입니다. 최초 프로그램 전체를 단독 개발한 것은 아닙니다.
- ASF, HC, MySQL 관리 스크립트, Threads 자동화, Vling 관련 업무에서 설명한 작업은 본인이 직접 수행했습니다.
- 학교 실습일지는 3개월간 수행한 업무를 15개로 정리한 자료이며, 실제 15일 출근 기록이 아닙니다.
- 2024년 10월 Vling 작업은 인턴 기간과 별도입니다.
- 과거 지원자료에 나오는 검증되지 않은 시간 단축 및 데이터 품질 개선 수치는 사실로 재인용하지 않았습니다.

## 공개 자료의 범위

이 저장소 및 링크된 기능별 저장소는 **회사 원본 코드, 데이터베이스, 수집 결과, 고객 정보, API 키, 내부 운영 문서를 포함하지 않습니다.** 기능별 `demo.py`는 포트폴리오 설명을 위해 새로 작성한 **오프라인 교육용 예제**로, 2024년 실제 소스나 원본의 배포 버전이 아닙니다.

직무별로 실무 경험을 이해할 수 있도록 배경, 설계 판단, 직접 수행한 활동과 보안상 공개하지 않는 범위를 구분해 기술했습니다. 프로젝트의 코드 공개와 저작권 사용 허가를 혼동하지 않기 위해 원본 파일은 어떤 저장소에도 업로드하지 않았습니다.

## 포트폴리오 읽는 방법

제조 IT 및 시스템 운영은 DB 관리와 프로세스 자동화, 데이터 직무는 ASF/HC와 Vling 파이프라인, 개발 직무는 기존 DM 최적화 및 오류 대응 기록을 중심으로 참고할 수 있습니다.

연락처와 개인 학교 서류, 회사 직인 문서는 공개하지 않습니다.

## 실행 가능한 독립 데모 및 검증

기능별 저장소에는 단순 설명뿐 아니라 **가상 데이터와 오프라인 로직으로 작성한 실행 예제, 오류 및 중복 처리 테스트, GitHub Actions**를 추가했습니다. 특히 Vling 저장소에는 로컬 Flask 대시보드와 조회 API가 있으며, 실제 회사와 연결되지 않습니다.

- [6개 저장소별 실행 방법](docs/DEMO_GUIDE.md)
- [업무 흐름의 공개용 일반화 구성도](docs/SYSTEM_MAP.md)

**구분:** 실무 경력은 2024년 당시 수행한 업무이고, 새로 작성한 실행형 데모는 2026년에 기능 이해를 보여주기 위해 만든 코드입니다. 데모 테스트 결과를 인턴 실적이나 실제 업무 성능 개선 수치로 표현하지 않습니다.
