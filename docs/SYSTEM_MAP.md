# 업무 경험과 데모 범위의 관계

아래는 당시 업무에서 경험한 흐름을 설명하기 위한 일반화된 구성도입니다. 실제 회사의 네트워크, 데이터베이스 및 시스템 구성도와 동일하지 않습니다.

~~~mermaid
flowchart TD
 A[판매자 후보 탐색 ASF] --> B[활동 데이터 수집 HC]
 B --> C[후보 정보 검토]
 C --> D[메시지 및 대상 DB 운영]
 D --> E[기존 DM 자동화 최적화]
 E --> F[결과 기록과 운영]

 G[Threads 계정 및 응답 관리] --> F

 H[10월 별도 Vling 채널 수집] --> I[채널 DB]
 I --> J[YouTube 영상 데이터 수집]
 J --> K[데이터 조회 및 수동 메모]
~~~

## 설계 판단

- 원본을 공개하지 않고도 동작을 재현할 수 있도록 모든 코드에 새로 만든 가상 데이터를 사용합니다.
- 실제 서비스에 자동 발송하거나 웹 페이지를 크롤링하지 않고, 상태 관리, 오류 처리, 데이터 검증, 저장 및 조회 등 개발상의 문제만 독립적으로 재현합니다.
- 프로젝트별 README에는 실무에서 수행한 활동과 현재의 데모를 각각 구분했습니다.
- 10월 프로젝트를 인턴 기간에 합산하지 않았습니다.
