# 경력 구분과 공개 원칙

## 기간

- 2024-07-01 ~ 2024-09-30: 디노스튜디오 인턴.
- 2024년 10월 약 2주: 별도 Vling 기반 데이터 수집 및 저장 작업.

## 개발 기여

- 기존 Instagram DM 발송 프로젝트: 원본 신규 개발이 아닌 최적화와 실무 운영 개선.
- 그 밖의 설명된 기능: 본인 직접 개발 및 개선.
- YouTube 관련 2024년 7월 노트북이 존재하지만 최초 작성 연혁 및 당시 운영 범위는 확인되지 않았으므로 10월 Vling 과업과 혼동하지 않음.

## 안전한 공개 범위

공개 자료는 사실 요약, 일반화한 설계도, 새로 만든 더미 데이터 코드로 한정합니다. 내부 DB, 원본 코드, 실수집 데이터, 영업 전략, 계정, 인증 정보 및 고용 증빙 원본은 공개하지 않습니다. 임의 성과 수치는 넣지 않습니다.

## 근거 문서

개인용 비공개 경력 아카이브와 학교 실습 서류를 별도로 보관합니다. 실제 원본 증빙 파일의 경로와 이미지 내용은 이 공개 저장소에 복사하지 않습니다.
